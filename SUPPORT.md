# Getting Support

## Documentation

Start with [README.md](README.md) for an overview and [docs/README.md](docs/README.md) for the scope, decisions and design. Recent changes are in [CHANGELOG.md](CHANGELOG.md).

## Questions and bugs

Ask questions and report bugs in [GitHub Issues](https://github.com/TechSpokes/wp-http-client/issues/new/choose) using the matching issue form.

For a bug, include the package version, the WordPress and PHP versions, a minimal code sample, and the output of `http_api_debug` with tokens, cookies and other secrets removed.

## Security issues

Do not post vulnerabilities in public issues. Follow the [Security Policy](SECURITY.md).
