# Triage labels

The triage skills speak of five roles. This repository uses the default label for each role unchanged.

| Role | Label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | The maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AI assistant |
| `ready-for-human` | `ready-for-human` | Needs a person to implement |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill names a role, apply the label in the second column. The issue forms add `needs-triage` to new bug reports and feature requests.
